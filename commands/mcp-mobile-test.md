# MCP Mobile Test — проверка на устройстве

Проверку ведёт субагент `@mobile-tester`. MCP `artemis` и `mobile` подключены **только у него** — inline `mcpServers` в `~/.claude/agents/mobile-tester.md`: процессы стартуют при его запуске и закрываются по завершении. В главной сессии этих тулов нет намеренно: каждая сессия экономит ~0,55 GB RAM (improvements `2026-10-23-mcp-scope-subagents`). Не ищи `mcp__artemis__*` через `ToolSearch` и не обходи — спавни агента. Процедура прогона, шаблон сценария и разбор сбоев ARTEMIS живут в агенте.

Разделение труда прежнее: **Claude (подписка) думает, ARTEMIS (дешёвая Gemini-модель по API) кликает.** Бесплатный тариф Gemini: запросы и скриншоты Google использует для обучения — риск принят пользователем 2026-09-30.

## Аргументы

`$ARGUMENTS` — package, что проверять, уровень (`smoke` / `screen` / `flow` / `deeplink` / `full`). Пусто — `AskUserQuestion`.

## Шаги главного

1. **Устройство.** `adb devices -l`. Устройств несколько — выбор через `AskUserQuestion` (у субагента его нет), дальше явный `device_serial`. Пусто — попроси подключить телефон или запусти `/install-emulator`: он поднимет AVD.
2. **Сборка.** Свежая — `/install-device` или `/install-emulator` до спавна.
3. **Спавн `@mobile-tester`** с брифом. Код экрана, который ты уже читал в задаче, передавай путями и выдержками, а не названием фичи:
   ```
   Package: <applicationId>
   Устройство: <serial>
   Сборка: <чем и когда установлена | путь к APK>
   Что проверить: <ожидаемое поведение / критерий приёмки задачи>
   Уровень: <smoke | screen | flow | deeplink | full>
   Код экрана: <пути к Composable, strings.xml, testTag>
   Стартовое состояние: <залогинен ли, какие данные, откуда начать>
   ```
4. **Отчёт агента — пользователю:** статус, пути к кадрам. `MANUAL` → блок «Сделай руками», перепроверив шаги своими инструментами. `FAIL` с багом приложения → фикс специалисту по обычным правилам, затем повторный спавн с тем же брифом.
5. `NEEDS_INPUT` → уточни у пользователя и `SendMessage` тому же агенту. `BLOCKED` по MCP → покажи пользователю строку починки из отчёта.

## Как включить ARTEMIS и `mobile` в главной сессии

Нужно редко: ручной разбор вместе с пользователем, `mobile` для iOS-симулятора, desktop или браузерного модуля. Включает пользователь, на одну сессию — перезапуском с продолжением диалога:

```powershell
claude --continue --mcp-config "$HOME/.claude/config/mcp/device.json"
```

Ничего не остаётся в конфиге: следующая сессия без флага стартует без этих серверов. Профиль `claude` — с `$env:CLAUDE_CONFIG_DIR=$null` перед командой.
