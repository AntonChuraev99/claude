# ADR: общий формат вывода SessionStart-хуков вместо агрегирующего раннера

**Статус:** Accepted · 2026-08-10

## Контекст

Блок, который сессия печатает на старте, стал нечитаемым. При разборе возникла идея свести
все SessionStart-хуки под один раннер, чтобы получить один аккуратный блок вместо нескольких
`says:`-врезок. Идея выглядит логично и почти наверняка вернётся — этот ADR существует, чтобы
она вернулась вместе с причинами, по которым была отклонена.

На момент решения в `settings.json` шесть SessionStart-хуков: `session-docs-digest`,
`review-rules/ensure-hook`, `ensure-worktree-guard`, `claude-md-size-guard`, `model-overlay`,
`credentials-digest`.

## Решение

Хуки остаются независимыми процессами. Общим делается **формат**, а не запуск: `lib/hookout.py`
задаёт единую форму вывода (`⚠ суть` + детали с отступом, без box-drawing, ширина от консоли),
и каждый печатающий хук через него проходит.

## Почему не раннер

1. **Агрегировать нечего.** На экран пишет ровно один хук — дайджест. `claude-md-size-guard`
   срабатывает по событию (CLAUDE.md перевалил лимит), `ensure-worktree-guard` — разово при
   регистрации гарда, остальные кладут только `additionalContext` и на экране не видны.
   Наблюдаемая «каша» была форматом одного хука, а не суммой нескольких.
2. **Цель всё равно не достигается.** Плагинные хуки (например caveman) живут вне
   `settings.json`, и раннер их не накрывает — второй `says:`-блок остаётся при любом раскладе.
3. **Единая точка отказа.** Сейчас каждый хук fail-open по отдельности: падение дайджеста не
   мешает `model-overlay` доставить калибровку модели, а `credentials-digest` — креды проекта.
   Раннер связывает шесть независимых отказов в один: его собственная ошибка гасит всё сразу.
   Обмен «чуть аккуратнее на экране» на «сессия может стартовать без калибровки модели и без
   кредов» невыгоден.
4. **Диагностируемость.** Хук, запущенный CLI напрямую, видно в `/hooks` и в статус-сообщении.
   Под раннером ошибка конкретного хука превращается в ошибку раннера.

## Следствия

- Новый печатающий SessionStart-хук обязан брать вывод из `lib/hookout.py`, а не изобретать
  рамку. Проверка при ревью: box-drawing символов в `systemMessage` быть не должно.
- `systemMessage` и `additionalContext` пишутся под разных читателей: экран получает факт,
  модель — инструкцию и полные данные. Копия одного текста в оба поля — дефект
  (так делал `claude-md-size-guard` до 2026-08-10).
- PowerShell-хук, печатающий не-ASCII, обязан выставлять `[Console]::OutputEncoding = UTF8` —
  иначе `⚠` уезжает байтом `0xa3`. Поймано smoke-тестом, а не глазами.
- Пересмотреть решение стоит, если печатающих хуков станет больше трёх ИЛИ появится
  возможность агрегировать плагинные хуки. Тогда сравнивать заново — с той же ценой в виде
  единой точки отказа.
