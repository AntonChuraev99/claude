# Делегирование прод-кода: правило без принуждения

**Дата:** 2026-08-27
**Область:** hooks / CLAUDE.md
**Статус:** open — берётся руками, внешней блокировки нет

## Что осталось

Правка 2026-08-27 (`improvements/2026-08-27-delegation-rule-erosion.md`) починила **форму** правила «прод-код пишет специалист»: закрыла два самоисполняющихся исключения и сняла конфликт с `model-overlays/opus-5.md`. Принуждения она не добавляет — по явному решению пользователя хук в той задаче не заводился.

`skills/instruction-routing/SKILL.md` (стр. 70) на этот случай говорит прямо: правило записано и нарушается → либо хук, либо признать необязательным. Тот же отказ уже принимался осознанно в `improvements/archive/2026-08-03-instruction-architecture-refactor.md` (приватный архив, в опубликованном дереве файла нет — см. `improvements/ARCHIVE.md`), и правило после него всё равно эродировало — до нуля вызовов код-специалистов 26.08 при 236 правках кода вне `~/.claude` (704 правки файлов) главным за день.

## Триггер, по которому стоит взяться

Replay improvement'а 2026-09-10. Если **среднее** вызовов доменных специалистов на сессию (`спец ÷ сессий` за день) не вернулось к ≥ 2.0 — форма была не единственной причиной, и остаётся хук.

## Набросок решения

`PreToolUse` на `Edit`/`Write`/`MultiEdit` главного агента:

- считать правки файлов с исполняемыми расширениями в пределах задачи (границу задачи брать по последнему прогону `/task-gate` либо по счётчику в state-файле сессии);
- на пороге (~15) — не блокировать, а вернуть `additionalContext` с напоминанием и именем профильного агента по расширению файла (лексический адресат работает, плейсхолдер — нет: `skills/subagent-authoring/SKILL.md` стр. 103);
- на верхнем пороге (~25) — `deny` с требованием делегировать или получить явное слово пользователя, снимается переменной окружения по образцу `CLAUDE_ALLOW_CODE_GREP`.

Механика полностью повторяет `hooks/bash-tool-discipline.js` — там этот паттерн (порог → сообщение с альтернативой → снятие переменной) уже отлажен.

## Известные ограничения заранее

- Хук видит **только файловые инструменты главного агента**: запись через `Bash` и правки фоновых субагентов мимо него — та же дыра, что в [protected-branch-bash-writes](protected-branch-bash-writes.md).
- Порог, выставленный слишком низко, даст обратный перекос — специалистов будут звать на однострочники. Anti-target из improvement'а: медиана `Agent` за 10 на сессию при том же объёме правок.
