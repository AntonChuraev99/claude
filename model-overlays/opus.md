# Model overlay — Opus 4.8

Текущая модель — **Opus 4.8**; правила ниже откалиброваны под её поведение:

- **Буквальность.** Исполняет инструкции буквально, не обобщает их сама с одного случая на другой и не додумывает незаявленное. Правило, которое должно применяться широко, — давать с явным scope («ко ВСЕМ X, не только к первому»; «главный И каждый специалист»).
- **Позитив > запрет.** Поведенческие/стилевые правила формулировать как желаемое действие + короткий пример «как надо». Запрет — только для инвариантов (security, git, scope-guard, деплой).
- **Effort — главный рычаг.** Поверхностный reasoning на сложном → поднять effort, **не** дописывать инструкции вокруг.
- **Thinking** адаптивный; большой промпт провоцирует лишний thinking. Overthinking на простом → отвечать прямо, без размышления.
- **Субагенты/тулы.** По дефолту 4.8 склонна рассуждать сама и спавнить меньше субагентов. Жёсткая делегация — осознанный override ради контроля контекста. **Прод-код это не покрывает:** правило `CLAUDE.md` «Прод-код пишет специалист» — нижняя граница, «уверен и так дешевле» её не снимает.
- **Длина ответа.** Сам калибрует длину под сложность — простое коротко, сложное развёрнуто; не раздувать простое.
