# Model overlay — Fable 5

Текущая модель — **Fable 5** (Mythos-class). Тюнинг под её поведение; дельты от Opus 4.8:

- **Склонна ДЕЙСТВОВАТЬ, а не переспрашивать (эмпирика, 2/2 проб).** На неоднозначной задаче Fable излагает критерий выбора / допущения и идёт дальше; Opus в тех же пробах чаще заканчивает явным уточняющим вопросом. Автономность — плюс, НО отсюда инвариант тем важнее: **реальная развилка (потеря функции / необратимое / неоднозначный scope) → `AskUserQuestion`, держать жёстко** — на её инстинкт «продолжить» тут не полагаться.
- **Делегация/субагенты — по докам её стихия** (long-horizon agentic: сама декомпозирует, делегирует, планирует по стадиям, самопроверяется, меньше mid-task check-in'ов). В single-shot пробах не проверялось → не подавляй, но и не считай доказанным. Инвариантные гейты (DoD, scope-guard, security, git) — держать.
- **На тривиальном не многословна (эмпирика: паритет с Opus).** Проба-переименование: вернула ровно код, без преамбулы. «Overthink на простом» — НЕ её специфичный риск; отвечать прямо умеет и так. (Чуть медленнее Opus — больше upfront-thinking даже на мелком; не проблема.)
- **Reasoning-качество и сопротивление overengineering — на уровне Opus (эмпирика).** Обе явно отвергли спекулятивные vararg/generics «на вырост», нашли один реальный баг. Буквальность + «не усложнять без запроса», правило широкого действия с явным scope — общая Claude-5-практика, применима.
- **Effort — тот же рычаг.** Дефолт — баланс, highest — для самых сложных. Поверхностный reasoning на сложном → поднять effort, **не** дописывать инструкции вокруг.
- **Длина/структура.** Декомпозиция богатая; «кратко» соблюдает слабо (как и Opus) — нужно реально коротко → проси явно и ограничивай объём.

**Инфо (не инструкция):** safeguards Fable могут ~<5% запросов роутить на Opus 4.8; dual-use cyber/bio заблокированы классификаторами.

**Метод / дальнейшая калибровка:** профиль = доки Anthropic + 3 A/B-пробы (Fable vs Opus, 2026-07-23, n=1/проба — направленно, не финально).
