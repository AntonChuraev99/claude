# Однотипные соседи — проверить и предложить

## Цель
Агент правит один элемент из группы (ряд, таб, карточку) и молчит про соседей с тем же дефектом. Пользователь узнаёт сам и тратит ещё одну задачу.

## Baseline (до изменений, на дату 2026-10-01)
Один зафиксированный случай в `<your-project>`. Веб: одному ряду экрана вернули удаление по долгому нажатию. У двух соседних рядов того же экрана было то же расхождение с Android, и их не назвали. Пользователь попросил то же следующей задачей. Счётчика нет, считаем по жалобам такого вида.

## Гипотеза
Правило загружается вместе с файлами кода (`rules/user-feedback.md`, `paths` по `*.kt/*.ts/*.tsx/*.js/*.jsx`) рядом с анти-регрессией. Оно делает обход соседей обязательным шагом перед отчётом. Решение остаётся за пользователем: агент только предлагает.

## Изменения
- `rules/user-feedback.md`: новая секция «Однотипные соседи — проверить и предложить».

## Target
К 2026-10-20 нет повторных просьб «сделай то же для соседнего X». В отчётах по UI-правкам есть строка про соседей.
