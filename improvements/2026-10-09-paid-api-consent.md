# Запрет платных трат без разрешения

## Цель
Агент в `<your-project>` без ведома пользователя потратил около $30 через платный API по ключу. Правила харнесса трату денег не регулировали.

## Baseline (до изменений, на дату 2026-10-09)
1 инцидент, около $30. Правила о платных вызовах в `CLAUDE.md` нет.

## Гипотеза
Явный инвариант в `CLAUDE.md` («сначала подписка, иначе `AskUserQuestion` с суммой; ключ в окружении — не разрешение») закрывает трактовку «ключ есть — значит можно».

## Изменения
- `CLAUDE.md` → «Автономность»: абзац «Тратить деньги без явного разрешения пользователя запрещено».

## Target
0 неразрешённых платных трат к 2026-10-23; источник — биллинг-консоли провайдеров и жалобы пользователя. Повтор → нужен хук на вызовы платных API (детект ключей `*_API_KEY` в командах).
