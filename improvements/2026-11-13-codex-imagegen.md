# Картинки через Codex CLI на подписке ChatGPT

## Цель

Пользователь платит за подписку ChatGPT и хочет, чтобы харнесс сам генерировал картинки. Платный OpenAI API для этого не нужен: Codex CLI с входом через ChatGPT содержит встроенный скилл `$imagegen` (gpt-image-2), и его генерации идут в лимиты подписки.

## Baseline (до изменений, на дату 2026-11-13)

Растровую картинку на подписке ChatGPT харнесс получить не мог: своего механизма нет. Поэтому baseline метрики — ноль вызовов (источник: скилла до этого PR не было). На replay метрика считается по JSONL сессий: `grep` вызовов `codex-imagegen/scripts/imagegen.sh` и их кодов выхода (5/6 — сбой), плюс поиск `OPENAI_API_KEY` и `--with-api-key` в командах агента. Codex CLI на машине не стоял.

## Гипотеза

Тонкая обёртка над официальным `codex exec` надёжнее сторонних скиллов и MCP. Сторонние варианты либо исполняют чужой код, либо берут токен ChatGPT и ходят в API в обход клиента, что нарушает ToS и грозит блокировкой аккаунта. Скилл без MCP не добавляет памяти в сессию.

## Изменения

- `skills/codex-imagegen/SKILL.md` — когда звать, промпт, проверка результата, лимиты.
- `skills/codex-imagegen/scripts/imagegen.sh` — `codex exec --enable image_generation --sandbox read-only`, поиск новой картинки в `generated_images`, копия в `--out`, режим правки через `--ref` (`codex exec -i`).
- `.gitignore` — whitelist скилла.

## Выводы по реализации

- Codex 0.167 на Windows запускает песочницу `read-only` даже с `--sandbox workspace-write`, поэтому файл в рабочий каталог не пишет. Картинка всегда лежит в `~/.codex/generated_images/<session>/`, и скрипт копирует её сам.
- `codex exec` ждёт ввод из stdin; без `</dev/null` вызов из агента может зависнуть.
- `-i <FILE>...` принимает несколько значений, поэтому промпт идёт после `--`, иначе Codex читает его как путь к картинке.
- Вход через API-ключ скрипт отклоняет, а `OPENAI_API_KEY` убирает из окружения вызова: API берёт деньги за каждую картинку.
- Первая версия брала самую новую картинку во всём `generated_images`. Ревью нашло гонку: при параллельных вызовах вызов A мог забрать картинку B. Теперь скрипт берёт `session id:` из вывода `codex exec` и ищет только в папке этой сессии.
- Таймаут скрипта стоит 540 с, ниже потолка 600 с инструмента Bash: иначе инструмент обрывал вызов раньше, и хвост лога терялся.
- Прогон 2026-11-13: генерация иконки и правка цвета по референсу прошли; время вызова не замерялось.

## Target

К 2026-11-27 картинки в задачах идут через скилл без кодов 5/6, и ни один вызов не ушёл в платный API.
