# Субагент video-expert

## Цель

Пользователь попросил субагента для создания видео: основы ремесла, видео через Opus 5.5, актуальные популярные видео-скиллы. До этого был только скилл `ui-demo-video` (2026-10-05) — узкий: сцена интерфейса для сайта и её экспорт; исполнителя рендера не было, рендер выпадал главному.

## Baseline (до изменений, на дату 2026-10-06)

Агента под видео нет. Одна видео-задача за историю (<your-project>, 2026-10-05): выбор инструмента потребовал внешнего скаута, рендер писал UI-специалист по скелету. Метрик по прошлым задачам нет — задач было мало.

## Гипотеза

1. Opus 5.5 видео не генерирует и видео на вход не принимает (vision-дока: только картинки) — путь «модель пишет код композиции → детерминированный рендер → проверка кадрами-PNG». Это закладывается в метод агента, иначе агент обещает «сгенерирую видео» или отчитывается без просмотра результата.
2. Выбор движка повторяется в каждой задаче: HyperFrames (Apache-2.0, HTML/GSAP → MP4, 57k★ на 2026-10-06) дефолт для ролика с нуля, Remotion — при уже существующем Remotion-проекте и с проверкой лицензии (компании >3 человек — платная), `ui-demo-video` — сцена сайта. Таблица в агенте убирает ресёрч.
3. Ремесло коротких роликов (хук 1–1,5 с, время чтения текста, без звука, safe zones, петля/CTA) держится инвариантами в теле, числа — в справочнике.

## Изменения

- Новый `~/.claude/agents/video-expert.md` (opus, effort high): шесть блоков, таблица движков, раскадровка до кода, проверка кадрами из готового файла и `ffprobe`.
- Новый `~/.claude/agents/video-expert/README.md`: команды установки HyperFrames и Remotion (из README, 2026-10-06), лицензии, что видит модель, форматы и кодирование, safe zones (вторичные источники, помечены), ремесло.
- Внешние скиллы глобально не ставятся — решение пользователя: агент возвращает `NEEDS_INPUT` с командой установки.
- Взаимные границы: `design-expert` и `marketing-expert` отдают видеоролик в `@video-expert`; `ui-demo-video` шаг 5 — рендер у `@video-expert`.

## Target

К 2026-10-20: первая видео-задача уходит в `@video-expert` по description, отчёт содержит `ffprobe` и прочитанные кадры; выбор движка без внешнего скаута.
