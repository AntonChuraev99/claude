# Скилл codex-second-opinion

## Цель

Перечитывание своего ответа той же моделью почти не повышает качество у
моделей с thinking: перепроверку они уже выучили при обучении. Модель другого
семейства ошибается в других местах. Скилл даёт главному агенту способ
получить независимое ревью диффа, диагноз бага или критику плана от Codex CLI
без оплаты API: вызовы идут по подписке ChatGPT.

## Baseline (до изменений, на дату 2026-11-27)

Второго мнения от другой модели в харнессе нет. Codex CLI вызывался только
для картинок (скилл `codex-imagegen`). Вызовов для текста — 0.

## Гипотеза

На задачах, где корень бага не найден после первого фикса, или на
рискованном плане Codex найдёт хотя бы часть дефектов, которые главный
пропустил. Находки Codex — гипотезы: главный проверяет каждую сам.

## Изменения

- `skills/codex-second-opinion/SKILL.md` — когда звать, приватность кода,
  вызов, что писать в промпт, как проверять ответ, лимиты.
- `skills/codex-second-opinion/scripts/ask.sh` — обёртка над `codex exec`
  (sandbox read-only, `--ephemeral`, без `OPENAI_API_KEY`) с режимами
  `review` (`codex exec review` с целью в тексте промпта), `debug`, `plan`,
  `ask`. Во всех режимах Codex получает правило не читать gitignored-файлы и
  `*.local.*`, `.env*`, `*credentials*`, `*secret*`.
- `.gitignore` — whitelist каталога скилла.

Две находки на Windows при живом прогоне 2026-11-27 (Codex CLI 0.167.2):

1. Без секции `[windows]` в `~/.codex/config.toml` Codex в `read-only`
   отклоняет любой процесс («blocked by policy») и не может прочитать код.
   Скрипт добавляет `-c windows.sandbox="unelevated"`: режим не требует прав
   администратора и запрещает запись (проверено: «Access denied» на запись).
2. Песочница не запускает `pwsh.exe` из Microsoft Store
   (`CreateProcessAsUserW failed: 5`). Скрипт убирает `WindowsApps` из `PATH`
   вызова, и Codex берёт системный `powershell.exe`.

По решению пользователя скилл **не встроен** в `/task-gate`: штатное ревью
диффа остаётся одно (2.3b).

## Target

К 2026-12-11: скилл вызывался хотя бы на 3 задачах, и хотя бы одна находка
Codex подтвердилась проверкой и изменила код или решение. Иначе — решить,
оставлять ли скилл.
