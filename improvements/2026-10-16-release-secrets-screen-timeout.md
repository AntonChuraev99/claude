# Секреты перед релизной сборкой и таймаут экрана на устройстве

## Цель

1. Релизная сборка из linked worktree не уходит без gitignored-ключей (`google-services.json`, keystore, ключи аналитики), которые есть в главном checkout.
2. Тест на физическом устройстве (USB или Wi-Fi) не срывается из-за того, что экран погас.

## Baseline (2026-10-16)

- Секреты попадают в worktree только по `.worktreeinclude`. Не хватило паттерна — `bundleRelease` собирался без ключа или со старым ключом, проверки не было.
- Таймаут экрана во время тестов никто не менял: на физическом устройстве экран гас посреди instrumented-теста, baseline profile или сценария.
- Чисел нет — нечем измерить: ни сборки без ключа, ни погасший экран нигде не логировались. Лечится так: модуль пишет `deny` и `repeat` в `~/.claude/stats/release-secrets-events.jsonl` (вне git); экран — поиском `screen_off_timeout` в JSONL-транскриптах сессий `@android-platform-expert`.

## Гипотеза

- Текстовое правило агент в момент сборки не видит, поэтому сверку держит хук: модуль в существующем Bash-префильтре, без нового спавна на каждую команду.
- Таймаут экрана — инструкция в теле `@android-platform-expert`: грузится только с агентом, не привязана к конкретному инструменту тестирования. Watcher и хук на инструмент пользователь отклонил: Wi-Fi-отладка держит устройство подключённым всегда, а привязка к ARTEMIS или команде ломается при смене инструмента.

## Изменения

- `hooks/release-secrets-guard.js` — новый модуль: `gradlew … (bundle|assemble|publish)*Release` → каталог сборки из команды (`cd`, `-p`, путь к gradlew), для linked worktree — сверка gitignored-файлов главного checkout (паттерны `.worktreeinclude` с исключениями `!x`, иначе стандартный список) по наличию и sha256; расхождение → deny со списком и командами `mkdir -p && cp`; повтор той же команды проходит один раз, следующий запуск сверяется заново; события — в `stats/release-secrets-events.jsonl`.
- `hooks/credentials-guard-prefilter.js` — подключение модуля после жёстких запретов.
- `hooks/release-secrets-guard.tests.js` — 49 проверок на временном репозитории с worktree, включая сквозной прогон через префильтр.
- `agents/android-platform-expert.md` § «Чем докажешь» — сохранить `screen_off_timeout`, поставить большой, вернуть после прогона на физическом устройстве.

## Target

К 2026-10-30: ни одной релизной сборки из worktree без ключа главного checkout; deny хука, если были, закончились копированием файла или намеренным повтором с причиной в отчёте; ложных deny на сборке из главного checkout — ноль.
