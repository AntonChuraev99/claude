# Скилл gemini-generate

## Цель

Пользователь хочет вызывать конкретные модели Gemini для ответа и для
картинок по своему ключу и видеть, сколько стоит каждый вызов. Платные вызовы
пользователь разрешил, когда он сам просит генерацию.

## Baseline (до изменений, на дату 2026-11-27)

Вызова Gemini API из харнесса нет. Gemini CLI вошёл с API-ключом (запись в
Диспетчере учётных данных Windows). Ключ на бесплатном тарифе: модели
картинок отвечают `429` с `limit: 0`, у `gemini-3.8-flash` 20 запросов в
сутки.

## Гипотеза

Прямой вызов REST API (без агентного цикла Gemini CLI) даёт точный
`usageMetadata`, и стоимость считается по прайсу без лишних токенов на
системный промпт CLI.

## Изменения

- `skills/gemini-generate/SKILL.md` — когда звать, правило денег, вызов,
  выбор модели, сбои.
- `skills/gemini-generate/scripts/gemini.py` — подкоманды `models`, `text`,
  `image`; ключ из env или из записи Gemini CLI (JSON, ключ в
  `token.accessToken`); строка стоимости и сумма за день, лог в
  `~/.claude/stats/gemini-spend.jsonl`.
- `skills/gemini-generate/scripts/prices.json` — прайс стандартного платного
  тарифа на 2026-11-27 с датами будущих изменений цен.
- `skills/gemini-generate/tests/test_gemini.py` — 11 тестов на подбор цены и
  расчёт стоимости.
- `.gitignore` — whitelist каталога скилла.

## Target

К 2026-12-11: скилл вызывался хотя бы на 3 задачах; сумма в
`gemini-spend.jsonl` за период совпадает со счётом AI Studio в пределах 10%
(если биллинг включён).
