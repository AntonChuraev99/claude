# Контрибьюшн-флоу харнесса: PR и GitHub issue

## Цель

Репозиторий публичный, его ставят другие люди. Нужен стандартный флоу: найденный и не исправленный сразу дефект — GitHub issue; любая правка — ветка и PR в `main`, без прямых коммитов. Внешний контрибьютор должен найти эти правила в репо, агент — получить их до первой правки.

## Baseline (до изменений, на дату 2026-10-06)

- `CONTRIBUTING.md`, шаблонов issue и PR нет. README не говорит, как предложить правку.
- Правило «PR, не коммит в транк» есть в CLAUDE.md для проектов, но для `~/.claude` снято: исключение «правка конфигов самого `~/.claude`» в разделе worktree, а `/task-gate` пропускал Step 6 (push/PR/merge) и снимал гард auto-commit на `main` для профильного репозитория. Правила «дефект харнесса, который не чиним, → issue» нет: отложенное уходило в `docs/backlog/` (10 записей) или терялось в чате.
- Число issue в репо до правки — не замерено; замерить `gh issue list -R AntonChuraev99/claude --state all` на replay.

## Гипотеза

Короткий указатель в CLAUDE.md + ленивый скилл дают агенту правило в момент правки харнесса без постоянной цены контекста. `CONTRIBUTING.md` и шаблоны `.github/` — стандартное место, где его ищут люди.

## Изменения

- `CONTRIBUTING.md` — правила для людей: issue на баг/идею, fork/ветка → PR, анти-утечка, whitelist `.gitignore`, запись в `improvements/`.
- `.github/ISSUE_TEMPLATE/{bug_report,feature_request}.md`, `.github/pull_request_template.md`.
- `skills/harness-contributing/SKILL.md` — процедура для агента: PR-флоу, поиск дубля и `gh issue create` по шаблону.
- `CLAUDE.md` § «Публичный репозиторий» — две строки-указателя на скилл; подробность про приватный архив `improvements/` сжата до ссылки, чтобы файл не вырос.
- `CLAUDE.md` § worktree — исключение для живых конфигов `~/.claude` уточнено: коммит всё равно через PR.
- `skills/task-gate/SKILL.md` (5.1.1, 5.1a, Step 6, 2.8) и `references/mr-merge.md` — `~/.claude` больше не выведен из PR-флоу; в харнессе TODO с якорем `// Issue: <url>` считается обеспеченным.
- `skills/commit/SKILL.md` шаг 0 — `~/.claude` больше не освобождён от вопроса про защищённую ветку.
- `.gitignore` — `!`-строки для новых файлов; `README.md` — раздел Contributing.

## Target

К 2026-10-20: все правки харнесса вошли через PR; каждый отложенный дефект харнесса за период — issue, а не новая запись в `docs/backlog/`.
