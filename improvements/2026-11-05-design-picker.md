# Страница выбора дизайна

## Цель

Пользователь выбирает вариант на глаз. `AskUserQuestion` не показывает скриншоты рядом, а пути к PNG в чате заставляют открывать файлы по одному. Нужна страница с вариантами, объяснением выбора и кнопкой, которая отдаёт результат агенту.

## Baseline (до изменений, на дату 2026-11-05)

Механизма нет: поиск по `rules`, `skills`, `agents`, `scripts`, `hooks` и `docs` прецедентов не нашёл. Долю задач нечем измерить: варианты дизайна в сессиях отдельно не размечены. Лечится подсчётом на replay: `grep` вызовов скилла `design-picker` в JSONL сессий против поля `Варианты` в ответах `@design-expert`.

## Гипотеза

Страница снимает лишний шаг открытия файлов и убирает ручной пересказ выбора. Запись в `db` артефакта делает передачу надёжной, поэтому сигнал через комментарий может быть необязательным.

## Изменения

- `skills/design-picker/SKILL.md` — процедура и схема `picker.json`.
- `skills/design-picker/assets/picker.html` — шаблон страницы без генерации кода на каждый запуск.
- `CLAUDE.md` § «Дизайн-фаза» — триггер: 2+ варианта на выбор идут на страницу вместо `AskUserQuestion`. Чтобы файл не вырос, снята строка «Стор-креатив»: тот же роутинг есть в описаниях `@design-expert` и `@marketing-expert`.
- `agents/design-expert.md` — поле `Варианты` в DESIGN_SPEC.
- `.gitignore` — whitelist скилла.

Выбран Artifact на claude.ai, а не локальный сервер: это решение пользователя. Цена — кадры уходят на claude.ai в приватный артефакт.

## Выводы по реализации

- Запись в `db` не будит сессию. Будит только `comments.sendToClaude`, и он работает после `await` записи в базу.
- Сессия получает событие `artifact-auto-react`, а ответ в тред уже написал автоответчик. Второй ответ агента был бы дублем.
- Republish без `files` оставляет старые `picker.json` и кадры: файлы, не переданные в вызове, сохраняются.
- Лимит комментария — 4 KiB в байтах, поэтому заметка на кириллице остаётся в базе, а не в сигнале.

## Target

К 2026-11-19 все задачи с 2+ вариантами дизайна проходят через страницу, а выбор читается из `choices/current` без пересказа в чате.
