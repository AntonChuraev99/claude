# doc-writer: распустить, писать главным, проверять хуком

## Цель

Убрать класс дефекта «правдоподобный, но выдуманный факт в долгоживущем документе» и перестать платить дважды за один документ (субагент пишет → главный перечитывает и переписывает).

## Baseline (до изменений, на дату 2026-09-15)

Все числа ниже сняты в сессии аудита 2026-09-15 python-скриптами по локальным файлам (gitignored, вне этого репозитория): `stats/doc-writer.md`, транскрипты `~/.claude/projects/*/*/subagents/` (дедуп по junction двух профилей), `agent-memory/doc-writer/`.

- **Фабрикации** (источник: Session Log в `stats/doc-writer.md`, 750 строк на дату аудита). С 2026-08-19 по 2026-09-15 22 строки упоминают `doc-writer`, **19 из них — «выдумал, переписан главным»**: сигнатуры и классы, пути, механизмы («фаза 2 на Cancelled»), замеры («crash 241», «84.1% n=2100»), описания собственных правок при готовом списке файлов в брифе, фантомные пути в `DOCS_WRITTEN`, дубли active/archive, битые ссылки в INDEX. Запись 2026-09-14: «восьмая задача подряд». Правило «копируй из источника, не по памяти» (improvement 2026-07-16) стояло в теле агента всё это время.
- **Стоимость** (источник: агрегация `.meta.json` + `.jsonl` транскриптов за 28 дней). 272 запуска: COMPLETE 125 (turns медиана 37, max 133; git-вызовов медиана 2, max 33 при cap «≤3»), UPDATE 91 (медиана 15 turns на append одной секции), INIT 53 (медиана 16 turns на стаб в одну `Write`). Суммарно ~580M cache-read, ~61M cache-create, ~2.9M output токенов. Плюс переписывание главным поверх.
- **Структурная причина.** Содержимое документа — «почему выбрали», «что провалилось», «какой был замер» — существует только в контексте главного. Субагент получал дифф и бриф, а правило тела (стр. 101 удалённого `agents/doc-writer.md`) объявляло бриф «не источником» → обязан реконструировать → выдумывал. Модель и effort тут вторичны (`effort: low` на haiku — по таблице `docs/en/model-config` вообще no-op).
- **Сопутствующее** (источник: листинг `agent-memory/doc-writer/`, gitignored). 57 файлов / 145K символов, из них 4 файла на понятие «active task», 13 одноразовых в `_archive/`, 23 проектных KMP-паттерна апреля; `MEMORY.md` 5.6K инъектился в каждый запуск. `reference_complete_phase.md` там же — мёртвая ссылка на `compose-feature-expert.md`, упразднённая классификация Trivial/Standard, проектные «нюансы Cloud Functions». Хук-напоминалка лежал в корне `~/.claude`, текст на упразднённых осях, в списке несуществующий агент `security-kotlin`, без `test-expert`. В `stats/doc-writer.md` — «Compound Effect» по упразднённым осям и колонка «errors avoided» = grep по словам «избежал|avoided».

## Гипотеза

По критерию Anthropic (`docs/en/sub-agents`: субагент — когда работа даёт verbose-вывод, не нужный в main; точечная правка — в main conversation; `claude.com/blog/subagents-in-claude-code`: сильнейший кейс — adversarial verification) генерация документа из уже известных главному фактов — работа главного, а не субагента. Проверка же имён, путей, ссылок и чисел детерминирована и не нуждается в модели вовсе: хук с `git grep` / `git ls-files` / `git diff` даёт список претензий за секунды и не может «поверить» правдоподобному имени. Ожидание: строки «выдумал / переписан» в Session Log → 0; findings хука в gate — единицы на документ и только внешние (SDK, чужой репозиторий), закрываемые маркером с причиной; документирование задачи — одна `Write` + одна `Edit` на итерацию + COMPLETE в контексте главного, без медианных 37 turns haiku сверху (источник: Baseline выше).

## Изменения

- **Удалено:** `agents/doc-writer.md`. `agent-memory/doc-writer/` (gitignored) оставлен как есть — проектные паттерны из него кандидат на перенос в `docs/solutions/` соответствующих проектов, отдельной задачей.
- **Новое:** `skills/doc-task/SKILL.md` + `references/templates.md` — стаб (INIT), строка итерации, COMPLETE (Выводы, постоянный документ, INDEX, архив, `DOCS_WRITTEN`), правило источников; шаблоны и правила `keywords:` перенесены из reference-файла памяти агента (источник: `agent-memory/doc-writer/`, gitignored) без проектного содержимого.
- **Новое:** `hooks/docs-facts-guard.js` (+ `.tests.js`, 63 кейса) — PostToolUse(Write|Edit|MultiEdit) на `docs/{solutions,decisions,archive}/**.md` и CLI для gate (`--base <sha>`, `--all`, exit 1 при претензиях). Классы `LINK` (блокер, маркером не закрывается) / `PATH` (блокер; вне репозитория — маркер с причиной) и `IDENT` / `NUMBER` (предупреждение, закрываются маркером с причиной или `источник:` в строке). Легаси не трогает: Write сравнивается с HEAD, Edit — только `new_string`, CLI с `--base` — с версией на базе задачи. Ревью диффа (2.3b) нашло и закрыло до мержа: ссылка извлекалась из код-блоков (`handlers[type](evt)` → ложный блокер), basename подтверждал выдуманный каталог, пути с `\` и `.github/` не распознавались, ASCII-`\w` резал «4 секции» в «4 сек», маркер снимал LINK, CLI не фильтровал легаси. Замер на репозитории ~19k файлов: 3 документа за 1.7 с; `git grep -F -f` с 66 паттернами не укладывался в 60 с — заменён на одну `-E -w -o` альтернацию (0.2 с). Калибровочный прогон по трём solution-докам, уже переписанным главным по факту: 2 / 4 / 5 претензий, все — внешний API либо константы времени, ложных срабатываний на реальные имена нет.
- **Перенесён и переписан:** `doc-writer-update-reminder.ps1` → `hooks/iteration-log-reminder.ps1` — напоминает главному дописать строку итерации; список специалистов сверен с реестром.
- `skills/task-gate/SKILL.md`: 2.4 → COMPLETE по `doc-task` + обязательный прогон `docs-facts-guard` (LINK/PATH → `❌`); 2.5 → стаб задачи; 2.6 → строка статистики из 5 колонок, собирает главный, grep-колонки упразднены; 2.7 → строку INDEX пишет главный; 2.7b — без фоновой гонки; Step 4 читает `## Предложения по улучшению агентов` из документа задачи; `references/{edge-cases,calibration,recommendations-pull,auto-commit-rules,diff-review-flow}.md` — согласованы.
- `CLAUDE.md`: Prompt Contract шаг 5, «Документирование» (кто пишет + хук), DoD-список. `README.md`, `rules/docs-structure.md`, `references/doc-length-budget.md`, `hooks/docs-length-guard.js` (комментарии и текст вердикта), `agents/{knowledge-scout,product-expert}.md`, `review-rules/{process-gate,backend-deploy}.yaml`, `settings.example.json` (новый хук, путь напоминалки), `.gitignore`.
- `skills/subagent-authoring/SKILL.md`: секция «Когда субагент не нужен» (прецедент); поля frontmatter `maxTurns` (соблюдается с v2.1.246, прежняя пометка про #41143 устарела), `omitClaudeMd`, `effort` на Haiku (источник: code.claude.com/docs/en/sub-agents и docs/en/model-config, сверено 2026-09-15).
- Локально, вне репозитория (не проверено хуком — файлы под gitignore): регистрация нового хука и нового пути напоминалки в локальном settings, в `stats/doc-writer.md` — таблица `## Session Log (с 2026-09-15)` на 5 колонок.

## Target

К 2026-09-29: в `stats/doc-writer.md` за период — ни одной строки с «выдумал / переписан главным» (baseline 19 за 4 недели); прогон `docs-facts-guard` в gate — медиана не выше трёх findings на документ, `LINK`/`PATH` в нуле на всех, ни одного закрытия маркером без причины; ни одного вызова `Agent` с `subagent_type: doc-writer` (агента нет — вызов упадёт, это и есть проверка, что ссылки вычищены). Anti-target: документы перестали писаться вовсе (больше каждой десятой задачи с признаком документирования проходит gate без документа) — тогда триггер 2.4 нужно усилить, а не возвращать субагента.
