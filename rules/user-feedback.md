# Обратная связь на каждое действие пользователя

На **любое** действие пользователя — видимый отклик: SideEffect (snackbar / toast / dialog) с причиной и с тем, что делать дальше.

```kotlin
// ✅ ввод пуст — сказать об этом, не выходить молча
if (stripped.isBlank()) { emitSideEffect(ShowSnackbar(HINT_EMPTY_INPUT)); return }
```

Любая форма тихого раннего выхода — `if (x.isBlank()) return`, `return@launch`, пустой `when`-else, `?: return`, ранний `guard` — для пользователя выглядит как зависание. Это баг, а не защита. Правило про **любой** молчаливый skip, не только про показанные формы.

Silent fallback в data-слое (`emptyList()`, `null`, дефолт вместо ошибки) — логировать `AppLogger.error` с причиной. Проглоченная ошибка без лога делает следующий баг недиагностируемым.

## Анти-регрессия при правке существующего компонента

Компонент уже умеет что-то — скролл, сохранение состояния, действие, ввод, навигацию — решение обязано сохранить **все** эти функции, у любого затронутого компонента, а не только у того, что в фокусе задачи.

Есть вариант без потери функции — берём его, даже если он сложнее. Единственный путь требует убрать существующую функцию — развилка через `AskUserQuestion` (что теряем / какая альтернатива) **до** реализации. Молчаливая отгрузка регрессии с пометкой «trade-off» постфактум — ошибка.

## Однотипные соседи — проверить и предложить

Правка касается одного элемента из группы однотипных: ряды или табы одного экрана, карточки разных типов, соседние шторки, тот же жест или действие у сестринских списков. Тогда **до отчёта** пройти по соседям группы: есть ли у них тот же дефект или та же недостающая функция. Нашёл — **в отчёте обязательно** (в Prompt Contract — дополнительно, если нашёл на старте) предложи строкой сделать то же: список соседей, что у каждого не так, оценка объёма; решение — за пользователем, развилку посреди задачи не открывать. Молча чинить только один элемент — ошибка, даже если запрос назвал один. Добавлять без спроса тоже нельзя: соседи идут в работу только по слову пользователя.

Признак группы — общий родитель в UI, общий паттерн в коде (`ARow` / `BRow` / `CRow` с одной структурой) или общий эталон на другой платформе. Прецедент 2026-10-01: на вебе одному ряду экрана вернули удаление по долгому нажатию, а у двух соседних рядов было то же расхождение с Android. Его не назвали, и следующей задачей пользователь просил то же самое повторно.
