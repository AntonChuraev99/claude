# Gemini: ответ и картинка по ключу

Скрипт `scripts/gemini.py` вызывает Gemini API напрямую. Ключ он берёт из
`GEMINI_API_KEY` или `GOOGLE_API_KEY`, а если их нет — из записи Gemini CLI
в Диспетчере учётных данных Windows (`gemini-cli-api-key/default-api-key`).
Ключ не печатается и не пишется в файлы.

## 1. Деньги

- Платный вызов разрешён, только когда пользователь сам попросил эту
  генерацию или этот ответ в текущей задаче. По своей инициативе (например,
  задаче нужен ассет) сначала спроси через `AskUserQuestion` с моделью и
  оценкой цены из `scripts/prices.json`. Субагент не спрашивает сам: он
  возвращает `NEEDS_INPUT` с моделью и оценкой цены, решает главный.
- Для картинки без запроса на Gemini бесплатный путь — `codex-imagegen`.
- После вызова передай пользователю строку `--- cost:` из stderr: цену
  вызова и сумму за сегодня. Лог расходов —
  `~/.claude/stats/gemini-spend.jsonl` (локальный, в git не попадает).
- Цена считается по прайсу на дату `as_of` в `prices.json`. Ключ на
  бесплатном тарифе не платит, строка показывает прайсовую цену. Модели нет
  в прайсе — стоимость `unknown`, токены всё равно печатаются.

## 2. Вызов

Bash вызывай с `timeout: 600000`. Скрипт ждёт каждую сетевую операцию до
300 с, и Bash не должен снять процесс раньше: иначе генерация уже оплачена,
а строки стоимости и записи в логе нет.

**Текст:**

```bash
python ~/.claude/skills/gemini-generate/scripts/gemini.py text \
  --model <модель> -- "<запрос>"
```

Флаги: `--system "<инструкция>"`, `--file <путь>` (картинка, PDF; можно
повторять), `--prompt-file <файл>` вместо текста после `--`.

**Картинка:**

```bash
python ~/.claude/skills/gemini-generate/scripts/gemini.py image \
  --model <модель> --out <абсолютный путь>.png [--aspect 16:9] [--size 2K] \
  -- "<описание>"
```

`--ref <картинка>` — исходник для правки или референс, можно повторять.
Пользователь не назвал путь — клади в scratchpad. Открой результат через
`Read` и посмотри сам до того, как отдать путь.

**Список моделей** (бесплатный вызов): `gemini.py models`.

Коды выхода: `2` — аргументы или файл, `4` — нет ключа, `5` — ошибка API
или сети (текст в stderr), `6` — пустой ответ или нет картинки.

## 3. Какую модель брать

Пользователь назвал модель — бери её. Не назвал:

| Задача | Модель | Цена (за 1M токенов, на 2026-11-27) |
|---|---|---|
| Быстрый дешёвый ответ | `gemini-3.5-flash-lite` | $0.30 вход / $2.50 выход |
| Обычный ответ | `gemini-3.8-flash` | $0.75 / $3.75 (с 2027-01-01 — $1.50 / $7.50) |
| Сложный ответ | `gemini-4-hydrogen` | $1.50 / $7.50 |
| Картинка дёшево | `gemini-3.1-flash-lite-image` | ≈ $0.034 за 1K-картинку |
| Картинка качественно | `gemini-3-pro-image` | ≈ $0.134 за 1K/2K, $0.24 за 4K |

Точный список доступных ключу моделей даёт `gemini.py models`.

## 4. Если сломалось

| Симптом | Действие |
|---|---|
| Код `4` | Ключа нет. Пользователь входит в Gemini CLI с API-ключом (`! gemini`, вход по ключу) или задаёт `GEMINI_API_KEY` |
| `HTTP 400: API key not valid` | Gemini CLI мог сменить формат записи. Сейчас это JSON, ключ в `token.accessToken`. Проверь формат, не печатая ключ |
| `HTTP 429` и `limit: 0` на free tier | У модели нет бесплатного лимита (все модели картинок). Нужен биллинг в проекте ключа: пользователь включает его в AI Studio |
| `HTTP 429` без `limit: 0` | Дневной или минутный лимит исчерпан. Предложи другую модель, в цикле не повторяй |
| Цена `unknown` | Модели нет в `prices.json`. Сверь цену со [страницей цен](https://ai.google.dev/gemini-api/docs/pricing), допиши строку и обнови `as_of` |

Цены меняются: перед крупной серией вызовов сверь `prices.json` со
страницей цен.
