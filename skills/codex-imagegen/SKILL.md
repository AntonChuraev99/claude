# Картинки через подписку ChatGPT

Codex CLI вошёл в аккаунт ChatGPT пользователя. Его встроенный скилл `$imagegen`
(модель gpt-image-2) рисует картинку и списывает её с лимитов подписки. Скрипт
`scripts/imagegen.sh` вызывает `codex exec` без интерактива и копирует PNG по
нужному пути.

## 1. Вызов

```bash
bash ~/.claude/skills/codex-imagegen/scripts/imagegen.sh \
  --out <абсолютный путь>.png -- "<описание картинки>"
```

- Правка или референс: добавь `--ref <картинка>`, флаг можно повторить. В
  промпте скажи, что оставить, а что поменять: «Keep the same icon and
  composition, change only the gradient to orange».
- Длинный промпт: `--prompt-file <файл>` вместо `-- "<текст>"`.
- Таймаут скрипта по умолчанию — 540 с, флаг `--timeout <сек>`. Bash вызывай
  с `timeout: 600000`: это потолок инструмента, и таймаут скрипта должен
  сработать раньше, иначе хвост лога не дойдёт. На macOS нужен `timeout` или
  `gtimeout` (coreutils), без них скрипт предупреждает и ждёт без лимита.
- Несколько картинок сразу (например, варианты для `design-picker`) можно
  запускать параллельно, каждую со своим `--out`. Скрипт ищет картинку в
  папке своей сессии Codex и чужую не возьмёт.
- Пользователь не назвал путь — клади в scratchpad, не в репозиторий.

Скрипт печатает путь результата. Коды выхода: `2` — аргументы, `3` — нет
Codex CLI, `4` — вход не через ChatGPT, `5` — `codex exec` упал (хвост лога в
stderr), `6` — Codex не создал картинку (его ответ в stderr).

## 2. Промпт

- Опиши сюжет, стиль, композицию, палитру и формат: «square», «16:9»,
  «1024x1024». Английский промпт модель понимает точнее.
- Текст на картинке пиши в кавычках и дословно.
- В тесте фон вокруг скруглённой иконки вышел белым. Прозрачный фон не
  проверялся. Если он нужен, проверь результат, а не обещай заранее.

## 3. Проверка результата

Открой PNG через `Read` и посмотри сам до того, как отдать путь пользователю.
Не то — уточни промпт или передай результат через `--ref` с правкой. Каждая
итерация тратит лимит, поэтому после двух неудачных попыток покажи лучший
вариант и спроси.

## 4. Деньги и лимиты

- Картинка расходует лимит Codex в 3-5 раз быстрее обычного запроса. На
  бесплатном плане ChatGPT генерации нет (источник: страница Codex pricing на
  learn.chatgpt.com, проверено 2026-11-13).
- После лимита подписки Codex списывает prepaid credits, если они есть.
  Скрипт это не блокирует, поэтому при серии картинок следи за ответом Codex.
- Скрипт отказывается работать при входе через API-ключ (код `4`) и убирает
  `OPENAI_API_KEY` из окружения вызова. Не обходи это: API платный за
  картинку, а трата денег требует явного «да» пользователя.
- Codex написал, что лимит исчерпан или нужны credits — остановись и скажи
  пользователю. Сам credits не покупай и не включай.

## 5. Если сломалось

| Симптом | Действие |
|---|---|
| Код `3` | Пользователь ставит CLI: `npm i -g @openai/codex` |
| Код `4` | Пользователь входит сам: `! codex login`, вариант «Sign in with ChatGPT» |
| Вызов висит | Скрипт уже закрывает stdin (`</dev/null`). Висит дальше — смотри лог в stderr после таймаута |
| Код `6` | Картинки ищутся в `${CODEX_HOME:-~/.codex}/generated_images/<session id>/`. Проверь, что Codex не сменил каталог или строку `session id:` в выводе, и обнови скрипт |
| Предупреждение `session folder not found` | Скрипт взял самую новую картинку во всём каталоге. При параллельных вызовах она может быть чужой — открой и проверь |

Codex на Windows запускает песочницу `read-only` даже с `workspace-write`,
поэтому файл в рабочий каталог не пишет. Скрипт берёт картинку из папки
сессии в `generated_images` и копирует её сам.
