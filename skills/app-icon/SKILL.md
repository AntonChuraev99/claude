# Иконка приложения через Codex

Иконку в сторе видят размером 48 px рядом с десятками похожих. Поэтому скилл судит
вариант не по картинке 1024, а по полке и по рабочему столу телефона, и оба кадра
строит сам до того, как показать пользователю.

Генерация идёт через скилл `codex-imagegen` (gpt-image-2 на подписке ChatGPT). Его
правила про деньги и лимиты действуют здесь целиком: исчерпан лимит — стоп и вопрос.

## 1. Вход — до первого промпта

Два независимых сбора, одним сообщением:

- **Проект** — `@knowledge-scout`: прошлые концепты иконки и их статус (принят,
  отвергнут, пауза, причина), дословные замечания владельца, палитра бренда в hex,
  запреты («только фирменный цвет», «не как конкурент X»), где лежит текущая иконка
  (`ic_launcher*`, `*-playstore.png`, favicon). Отдельно проверь project memory по
  словам icon / иконк / logo / brand.
- **Практики** — `references/best-practices.md` в этом скилле. Свежая сверка с сетью
  (`@best-practices-scout`, `SCOUT_MODE: quick`) — только если файлу больше полугода
  или пользователь просит iOS / новую платформу.

Решения владельца из прошлых раундов — обязательные ограничения, их не предлагают
заново. Самую сильную прошлую зацепку бери в набор как один из вариантов.

Нужна полка конкурентов: 6-8 PNG иконок из поиска стора по главному ключу категории.
Нет в проекте — собери через `mcp__appstore__search_app` / `get_app_details`
(поле icon) в `<scratchpad>/competitors/`.

## 2. Промпты

База — `references/prompt-template.md`: full-bleed квадрат без своих скруглений,
рамки и внешней тени, один глиф на ~55% ширины, палитра строго из бренда, без текста.
К базе — по одному концепту на вариант.

- 4-6 вариантов, **разные формы**, а не перекраска одной: галочка, объект-метафора
  продукта («что угодно → результат»), буквенный знак, тактильный объект и т.п.
- Если вся полка одного цвета, а бренд тот же — отличаться формой и акцентом.
- Акцент (искра, плашка «AI», бейдж) не меньше ~1/4 глифа и с явным зазором:
  в круге лаунчера мелкий акцент превращается в точку.
- Блёстка-«AI» — только акцент, не главный объект: пользователи не читают её как AI
  (NN/g, 2024; ссылка в best-practices).

Промпты — файлами `<scratchpad>/icons/prompts/<id>.txt`, id латиницей (`v1-glossy-check`).

## 3. Генерация — параллельно

```bash
D=<scratchpad>/icons
mkdir -p "$D/out" && rm -f "$D/out/status.txt"   # без out/ редирект лога падает и ни один вызов не стартует
for p in "$D"/prompts/*.txt; do n=$(basename "$p" .txt)
  ( bash ~/.claude/skills/codex-imagegen/scripts/imagegen.sh \
      --out "$D/out/$n.png" --prompt-file "$p" > "$D/out/$n.log" 2>&1
    echo "$n exit=$?" >> "$D/out/status.txt" ) &
done; wait; cat "$D/out/status.txt"
```

Bash — с `run_in_background: true`: 6 картинок идут 3-6 минут. Правка готового
варианта — `--ref <png>` и список «что оставить / что поменять».

## 4. Проверка — сам, до показа

Открой каждый PNG через `Read`. Брак, который перегенерируется:

- скругления, рамка, внешняя тень, мокап телефона, лишний текст;
- цвет вне палитры бренда;
- акцент касается глифа, хотя промпт просил зазор;
- глиф шире ~65% или прижат к краю (обрежет маска).

Codex отдаёт квадрат 1254×1254 RGB без альфы: для Play это правильно, размер
приводится к 512 на шаге 5. Два неудачных повтора одного варианта — покажи лучший
и спроси.

## 5. Кадры, по которым выбирают

```bash
python -I ~/.claude/skills/app-icon/scripts/shelf.py <out> <competitors> <picker>/shots
python -I ~/.claude/skills/app-icon/scripts/phone_mock.py <phone_dir> <competitors> \
  --size 1080x2424 --density 460 "v1=<out>/v1.png" "v5=<out>/v5.png"
```

- `shelf.py` — для каждого варианта `*-512.png` (маска Play 30%) и `*-shelf.png`
  (48 px @2x среди конкурентов, светлая и тёмная тема, наш — над золотой чертой).
- `phone_mock.py` — рабочий стол в разрешении телефона, круглая маска лаунчера,
  иконка ~56 dp. Размер и плотность бери с устройства: `adb shell wm size`,
  `adb shell wm density` (Override, если есть). Без `--size/--density` — 1080×2424 @ 420.

Текущую иконку (для `v0` на шаге 6) положи в `<out>` как `v0-current.png` до запуска
`shelf.py`: обычно это `*-playstore.png`; `.webp` — сконвертируй Pillow
(`Image.open(p).save(...png)`). `phone_mock.py` принимает до 6 иконок.

Посмотри обе картинки сами и назови в отчёте, что теряется на маленьком размере.

## 6. Выбор

Скилл `design-picker`: один вопрос, вариант = кадры `*-512.png` + `*-shelf.png`,
плюс текущая иконка как `v0` для сравнения. `recommended` — у варианта с самым
сильным силуэтом на полке, причина — в `summary`.

**«Хочу на телефоне»** — собери `phone_mock.py` с выбранными вариантами и положи
файлы в галерею:

```bash
export MSYS_NO_PATHCONV=1   # Git Bash на Windows иначе превращает /sdcard в C:/Program Files/Git/sdcard (проверено 2026-11-13)
adb -s <serial> shell mkdir -p /sdcard/Pictures/AppIcons
adb -s <serial> push <phone_dir>/home-light.png /sdcard/Pictures/AppIcons/
adb -s <serial> shell am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE \
  -d file:///sdcard/Pictures/AppIcons/home-light.png
```

Устройство с несколькими подключёнными — бери физическое (`adb devices -l`, не
`emulator-*`). Интерфейс телефона не трогать: пользователь открывает файл сам
(Google Фото → «Папки на устройстве»), на весь экран — пиксель в пиксель.

## 7. После выбора

- Исходники, промпты и превью — в каталог ассетов проекта вне репозитория или в
  gitignored-папку, не в scratchpad: он временный.
- Play: 512×512 PNG32 sRGB ≤1024 KB из исходника 1254, без своих скруглений
  (источник: `references/best-practices.md` → «Google Play»).
- Adaptive icon (foreground / background / monochrome) и замена `ic_launcher*` —
  задача `@android-platform-expert` с исходником победителя: глиф в безопасную зону
  66 dp из 108, monochrome — силуэт глифа одним цветом.
- Тест иконки в сторе (store listing experiment) — решение `@marketing-expert`.
