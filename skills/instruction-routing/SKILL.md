# Куда класть инструкцию

Выбор — по двум вопросам: **как часто это нужно** и **можно ли позволить, чтобы правило не сработало**.

```
Обязано срабатывать ВСЕГДА, нарушение дорого или необратимо?
├─ ДА → хук (PreToolUse / PostToolUse / Stop). Единственный детерминированный вариант.
└─ НЕТ ↓
Привязано к типу файлов (только .kt, только docs/**, только тесты)?
├─ ДА → ~/.claude/rules/<тема>.md с paths:
└─ НЕТ ↓
Процедура, справочник или чеклист, нужный иногда?
├─ ДА → скилл ~/.claude/skills/<имя>/SKILL.md
└─ НЕТ → факт или инвариант на каждую сессию, 1-3 строки → CLAUDE.md
```

| Механизм | Когда грузится | Цена контекста | Надёжность |
|---|---|---|---|
| **CLAUDE.md** | каждая сессия, целиком | высокая, постоянная | модель может не выполнить |
| **`rules/*.md` с `paths:`** | когда Claude читает файл по маске | ноль, пока маска не совпала | модель может не выполнить |
| **`rules/*.md` без `paths:`** | каждая сессия, целиком | как у CLAUDE.md | так же |
| **Скилл** | описание — каждую сессию, тело — при вызове | низкая | модель может не подтянуть |
| **Хук** | на событии жизненного цикла | ноль, если не вернул вывод | гарантированная |

Инструкция в CLAUDE.md или скилле — просьба; `PreToolUse`-хук — принуждение. Правило, которое обязано держаться под нагрузкой, пишем хуком.

## CLAUDE.md

Только факты и инварианты, нужные каждую сессию. Потолок — **200 строк И 37 000 символов**, любой из двух. Второй бюджет введён 2026-08-31: строчный счётчик слеп к тому, как файл растёт на самом деле — 197 строк по ~178 символов проходили как «зелено». Оба гонит `hooks/claude-md-size-guard.py`.

- Тест каждой строки: *«если это убрать, Claude начнёт ошибаться?»* Нет — вырезать.
- Процедура на 30 строк — антипаттерн: оставляем **триггер в 1-3 строки** плюс ссылку, протокол уносим.
- «Never do X» словами — слабая конструкция. Либо переписать позитивно («делай Y»), либо оформить хуком.
- Раздутый файл не просто дорог: важные правила теряются в шуме и начинают игнорироваться целиком.

## `~/.claude/rules/`

```markdown
---
paths: ["docs/**", "**/*.kt"]
---
# Тема
```

- Файл на одну тему, имя говорящее: `docs-structure.md`, `user-feedback.md`.
- **`paths` обязателен.** Без него правило грузится каждую сессию с приоритетом `CLAUDE.md` — те же токены, только незаметнее. Нечего указать в `paths` — это не rule, а скилл или строка в CLAUDE.md.
- Срабатывает, когда Claude **читает** файл по маске. При создании файла с нуля может не подтянуться — критичный инвариант дублируем строкой-триггером в CLAUDE.md.
- `~/.claude/rules/` — личные для всех проектов, `.claude/rules/` в репозитории — командные, грузятся после личных и имеют приоритет.
- README и любые файлы без `paths` сюда не класть — молча уедут в каждую сессию.

## Скиллы

- **`description` — единственное, по чему модель выбирает скилл.** Конкретно: что внутри и на каких формулировках задачи нужно. Расплывчатое описание = скилл не подтянется никогда.
- **Загруженный скилл остаётся в контексте до конца сессии** — каждая строка это повторяющаяся стоимость. Пишем что делать, а не почему. Детальный справочник — в соседние файлы со ссылкой из тела.
- `disable-model-invocation: true` — для действий с побочными эффектами (`/commit`, `/deploy`); заодно убирает описание из контекста. `user-invocable: false` — для фонового знания.
- Скилл можно препоадить в субагента полем `skills:` — тогда содержимое уезжает в его контекст целиком при запуске.

**Скилл — не место для того, что модель и так делает.** Перед созданием проверить: не дублирует ли он `description` агентов, плагин-скилл или сжатую версию в CLAUDE.md. Ревизия 2026-08-03 удалила 7 из 10 свежесозданных скиллов именно по этому признаку.

## Хуки

`~/.claude/hooks/`, регистрация в `settings.json`. Для того, что обязано происходить одинаково каждый раз и не требует размышления: линт после правки, блокировка записи в защищённый путь, проверка перед завершением turn'а, инъекция контекста на старте.

Признак, что пора: правило уже записано в CLAUDE.md, но нарушается. Повторять громче бесполезно — либо в хук, либо признать необязательным.

## Уборка

- Дублируется в двух местах — оставить одно. Противоречащие правила модель разрешает произвольно.
- Субагенты **грузят** `CLAUDE.md` и `~/.claude/rules/` сами. Копировать это в определение агента не нужно.
- Правило перестало быть нужным — удалить, а не помечать «устарело».
- После переноса — `grep` по старому пути, чтобы не осталось битых ссылок в скиллах, хуках и агентах.

```bash
wc -l ~/.claude/CLAUDE.md          # < 200
head -4 ~/.claude/rules/*.md       # у каждого есть paths
```

`/context` в сессии показывает, что реально загрузилось. Правило не сработало — сначала проверить, загрузилось ли оно вообще.
