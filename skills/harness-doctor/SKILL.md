# harness-doctor

Две части. Скрипт `scripts/doctor.py` проверяет и чинит всё механическое. Агент
разбирает смысловые конфликты инструкций — скрипт их не видит.

Режим — **чинить сразу** (решение пользователя 2026-11-24): отчёт без починки
не нужен, кроме случаев из шага 4, где решение за пользователем.

Встроенный `/doctor` Claude Code проверяет саму установку Claude Code. Этот скилл
его не повторяет: в отчёте одна строка «здоровье Claude Code — `/doctor`».

## 1. Механическая проверка с починкой

```bash
python "$HOME/.claude/skills/harness-doctor/scripts/doctor.py" --project "<корень проекта>" --fix --json
```

Без `--project` — текущий каталог. Код выхода 1 — остался `fail`.

Что чинит `--fix` сам (`fix.kind: auto`):

| Проверка | Починка |
|---|---|
| CLI под стек не найден или ниже минимума | `winget install/upgrade -e --id …` (`gcloud` — руками, просит UAC) |
| нет индекса ast-index | `ast-index rebuild` в основном checkout'е, не в worktree |
| проекта нет в `config/protected-branches.local.json` | запись с транком из `origin/HEAD` |
| в реестрах пути, которых нет на диске | удаляет записи; копия реестра — `*.bak-doctor` рядом |
| нет git-хука `pre-commit`/`commit-msg` в `~/.claude` | копия из `hooks/` — denylist пользователь вписывает сам |

Остальные виды:

- `input` — нет строки в `config/project-credentials.local.md`, а у проекта есть деплой.
  Скрипт вывел строку с выведенными значениями и `<account>`. Спроси почту через
  `AskUserQuestion` (варианты — почты из соседних строк реестра) и повтори шаг 1
  с `--account <почта>`.
- `edit` — правка tracked-файла проекта (`.worktreeinclude`, `.gitignore`,
  проектный CLAUDE.md, settings). Делай в шаге 3 вместе с правками конфликтов.
- `manual` — только руками пользователя: в `## 👉 Сделай руками` с точной командой.

CLI поставлен, но не находится — PATH обновится после перезапуска терминала.
Это не повод ставить второй раз.

## 2. Конфликты инструкций

Поле `instructions` в JSON — список источников, которые Claude получает в этом
проекте: `global` (CLAUDE.md), `global-rule` (только rules, чьи `paths` совпали
с файлами проекта), `project`, `project-local`, `project-agents-md`,
`project-rule`, `nested`. Механические конфликты скрипт уже нашёл: `shadow-agents`,
`shadow-skills`, `allow-vs-deny`, `hook-dup`, `dead-agent-ref`, `override-*`.

Смысловой разбор:

- Сумма `chars` до ~60k — читай источники сам: глобальный CLAUDE.md уже в контексте.
- Больше — один `general-purpose` с брифом: список путей из `instructions`,
  классы и формат находки ниже, «только чтение, ничего не правь».

Класс находки:

| Класс | Признак |
|---|---|
| `contradiction` | два источника велят разное в одной ситуации |
| `duplicate` | проектный источник повторяет глобальное правило — дрейф при правке одного |
| `stale` | ссылка на удалённого агента, скилл, файл, команду, MCP |
| `silent-override` | проект меняет глобальное поведение, но не говорит, что это осознанное исключение |

Находка — `file:line` обеих сторон, цитата до 2 строк, что Claude сделает
неправильно. Стиль, тон и «можно короче» — не находки.

Частый случай: проектный `.claude/rules/ast-index.md` от плагина велит
`ast-index rebuild`/`update`, глобальный CLAUDE.md это запрещает. Это
`contradiction` — фикс по таблице шага 3.

## 3. Починка конфликтов

| Находка | Действие |
|---|---|
| `duplicate` | удали повтор из проектного файла |
| `stale` | замени на актуальное имя, если замена однозначна; иначе удали строку |
| `contradiction` по факту проекта (транк, команда сборки, стек, стиль) | оставь, переформулируй явным исключением: «В этом проекте вместо глобального „…" — …» |
| `silent-override` | то же — явное исключение |
| механические `edit` из шага 1 | `.worktreeinclude`/`.gitignore` — допиши строки `append`; тень агента — переименуй проектного; мёртвое allow и дубль хука — удали |

**Правки tracked-файлов проекта — через worktree проекта** (`EnterWorktree`,
slug `harness-doctor-fixes`), одной веткой, затем `/task-gate`. Файл не tracked
(`CLAUDE.local.md`, gitignored settings) — правь на месте.

Глобальную сторону (`~/.claude/CLAUDE.md`, `rules/`) этот скилл не правит: она
публичная и меняется только PR по скиллу `harness-contributing`. Дефект на
глобальной стороне — GitHub issue по тому же скиллу, ссылка в отчёт.

## 4. Когда спросить, а не чинить

`AskUserQuestion` до правки, если:

- `contradiction` задевает инвариант глобального CLAUDE.md: коммиты и push, трату
  денег, деплой и креды, защищённые ветки, ослабление тестов. Варианты: «оставить
  исключение проекта явным» / «убрать, действует глобальное правило».
- направление неясно — непонятно, какая сторона новее и верна.
- удаление проектного агента или скилла, который перекрывает глобальный.

## 5. Отчёт

1. Повтори шаг 1 без `--fix` и покажи итоговую строку скрипта.
2. Таблица: проверка · было · стало. Конфликты — списком `file:line` → что сделано.
3. `## 👉 Сделай руками` — все оставшиеся `manual` с командами и строка про `/doctor`.
