# Второе мнение от Codex

Codex CLI вошёл в аккаунт ChatGPT пользователя. Codex работает на моделях
другого семейства, поэтому ошибается в других местах, чем Claude. Проверка
чужой моделью ловит то, что не ловит перечитывание своего ответа.

## 1. Когда звать

- Пользователь прямо попросил второе мнение.
- Корень бага не найден, и один фикс уже не сработал.
- План задевает архитектуру или необратимое действие, и ты хочешь найти дыру
  до реализации.
- Ревью важного диффа вне `/task-gate`, когда нужен взгляд без твоего контекста.

Не зови на рутину: вызов идёт от десятков секунд до нескольких минут и тратит
лимит подписки.

## 2. Код уходит в OpenAI

Codex отправляет прочитанный код на серверы OpenAI. Песочница `read-only`
запрещает запись, но не чтение.

- Опубликованную часть харнесса `~/.claude` можно отправлять без вопроса.
  Gitignored-файлы харнесса приватны: `config/*.local.*`, память, статистика.
- Скрипт велит Codex не читать файлы, которые игнорирует git, и файлы
  `*.local.*`, `.env*`, `*credentials*`, `*secret*`. Это инструкция модели, а
  не запрет песочницы. Если в каталоге `--cd` лежат секреты вне git, укажи
  `--cd` уже, на подкаталог с кодом.
- Если проект закрытый или клиентский и пользователь в этой задаче не
  разрешил Codex, спроси через `AskUserQuestion` до вызова.

## 3. Вызов

Bash вызывай с `timeout: 600000` или с `run_in_background: true`. Таймаут
скрипта по умолчанию — 540 с (`--timeout <сек>`), он срабатывает раньше
потолка инструмента, и хвост лога доходит до тебя. Таймаут ставит `timeout`
или `gtimeout`. На macOS без coreutils их нет: скрипт предупреждает и ждёт
без лимита, поэтому там вызывай его только с `run_in_background: true`.

**Ревью диффа** — подкоманда `codex exec review`:

```bash
bash ~/.claude/skills/codex-second-opinion/scripts/ask.sh --mode review \
  --cd <репозиторий> --base origin/main
```

Вместо `--base` можно `--uncommitted` (staged, unstaged и untracked) или
`--commit <sha>`. Без флага берётся `--base origin/main`: рабочее дерево
против merge-base, незакоммиченные правки входят. Доп. указания — после
`--`: `-- "Сфокусируйся на гонках в ViewModel"`. Скрипт всегда называет цель
ревью в тексте промпта, а не флагом: Codex не принимает свой промпт вместе
с `--base`, `--uncommitted` и `--commit`, а встроенный пресет не получил бы
правило приватности.

**Корень бага, критика плана, вопрос:**

```bash
bash ~/.claude/skills/codex-second-opinion/scripts/ask.sh --mode debug \
  --cd <репозиторий> --prompt-file <файл>
```

`--mode plan` — критика плана, `--mode ask` — свободный вопрос. Короткий
текст можно передать после `--` вместо `--prompt-file`.

Скрипт печатает финальный ответ Codex. Коды выхода: `2` — аргументы, `3` —
нет Codex CLI, `4` — вход не через ChatGPT, `5` — `codex exec` упал или
вышел таймаут (хвост лога в stderr), `6` — Codex не дал финального ответа.

## 4. Что писать в промпт

Codex не видит твой контекст. Для `debug` дай: симптом с точным текстом
ошибки, шаги репро, что уже пробовали и почему не сработало, подозреваемые
файлы. Для `plan` — цель, сам план по шагам и ограничения. Свою гипотезу
корня в `debug` не подсказывай: так ответ остаётся независимым. Промпт
длиннее пары строк пиши в файл в scratchpad.

## 5. Как использовать ответ

- Каждая находка Codex — гипотеза, а не факт. Проверь её своими
  инструментами: открой `file:line`, запусти тест или репро.
- Подтверждённую находку чини по обычным правилам задачи. Неподтверждённую
  назови в отчёте одной строкой с причиной отказа.
- Codex и ты не согласны, и проверка не решает спор — покажи пользователю
  обе позиции.

## 6. Деньги и лимиты

- Скрипт отказывается работать при входе через API-ключ (код `4`) и убирает
  `OPENAI_API_KEY` и `CODEX_API_KEY` из окружения вызова. Не обходи это:
  API платный, а трата денег требует явного «да» пользователя.
- После лимита подписки Codex может списывать prepaid credits. Если Codex
  написал, что лимит исчерпан или нужны credits, остановись и скажи
  пользователю. Сам credits не покупай.

## 7. Если сломалось

| Симптом | Действие |
|---|---|
| Код `3` | Пользователь ставит CLI: `npm i -g @openai/codex` |
| Код `4` | Пользователь входит сам: `! codex login`, вариант «Sign in with ChatGPT» |
| Код `5` и в логе ошибка аргументов | Проверь `codex exec --help` и `codex exec review --help`: флаги CLI могли смениться. Обнови скрипт |
| Вызов висит | Скрипт уже закрывает stdin (`</dev/null`). Висит дальше — смотри лог в stderr после таймаута |
| Codex пишет, что команды «blocked by policy» и он не может прочитать код | На Windows без выбранной песочницы Codex отклоняет любой процесс в `read-only`. Скрипт сам добавляет `-c windows.sandbox="unelevated"`, если в `~/.codex/config.toml` нет секции `[windows]`. Секция есть — проверь её значение |
| В логе `CreateProcessAsUserW failed: 5` на `WindowsApps\pwsh.exe` | Песочница не запускает приложения из Microsoft Store. Скрипт убирает `WindowsApps` из `PATH` вызова, и Codex берёт системный `powershell.exe`. Ошибка осталась — проверь, какой shell Codex берёт теперь |
